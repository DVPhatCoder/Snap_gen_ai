The snapgen.ai Video Generation API allows you to create high-quality videos from text prompts using state-of-the-art Grok AI models. You can use this API to generate video content, animations, marketing materials, or any visual video content you can imagine.

## Extend Video Grok
`POST https://api.snapgen.ai/uapi/v1/video-extend/grok`

This endpoint allows you to extend an existing Grok video using its last frame as a reference.

### Example Request
::code-group
```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/video-extend/grok \
  -H "Content-Type: multipart/form-data" \
  -H "x-api-key: <your api key>" \
  --form "prompt=Continue the scene with more action" \
  --form "ref_history=<uuid of existing video>"
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/video-extend/grok"
headers = {
    "x-api-key": "<your api key>"
}
data = {
    "prompt": "Continue the scene with more action",
    "ref_history": "<uuid of existing video>"
}

response = requests.post(url, headers=headers, data=data)
print(response.json())
```

```javascript [js]
import axios from 'axios';
import FormData from "form-data";

const url = "https://api.snapgen.ai/uapi/v1/video-extend/grok";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("prompt", "Continue the scene with more action");
formData.append("ref_history", "<uuid of existing video>");

axios.post(url, formData, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```
::

### Request Parameters

`prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The text description for the video extension.

`ref_history` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The UUID of the original video generation history to extend.

### Response Fields

`id` - Unique identifier for the video generation request

`uuid` - Universal unique identifier for the generated video

`user_id` - User ID who initiated the request

`model_name` - Name of the model used for generation (e.g., grok-3)

`input_text` - The original prompt used for video generation

`type` - Type of media generated (e.g., "video")

`status` - Generation status (1: processing, 2: completed, 3: failed)

`status_desc` - Description of the current status

`status_percentage` - Progress percentage (0-100)

`error_code` - Error code if generation failed

`error_message` - Error message if generation failed

`expired_at` - Expiry time of the video resource

`name` - Name of the video (if any)

`estimated_credit` - Estimated credits used for this request

`media_type` - Media type, e.g., "video"

`created_at` - Date and time the request was created

`updated_at` - Date and time the request was last updated

`delay_seconds` - Delay in seconds before the video starts generating
