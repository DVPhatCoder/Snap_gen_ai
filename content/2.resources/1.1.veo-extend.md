The snapgen.ai Video Generation API allows you to create high-quality videos from text prompts using state-of-the-art AI models. You can use this API to generate video content, animations, marketing materials, or any visual video content you can imagine.

## Extend Video Veo
`POST https://api.snapgen.ai/uapi/v1/video-extend/veo`

This endpoint allows you to generate videos from text prompts using the Veo model. You can customize the resolution, duration, aspect ratio, and various other parameters to create the perfect video for your needs.

### Example Request
::code-group
```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/video-extend/veo \
  -H "Content-Type: multipart/form-data" \
  -H "x-api-key: <your api key>" \
  --form "prompt=A serene lake surrounded by mountains at sunset with gentle waves" \
  --form "ref_history=<uuid video>"
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/video-extend/veo"
headers = {
    "x-api-key": "<your api key>"
}
data = {
    "prompt": "A serene lake surrounded by mountains at sunset with gentle waves",
    "ref_history": "<uuid video>"
}

response = requests.post(url, headers=headers, data=data)
print(response.json())
```

```javascript [js]
import axios from 'axios';

const url = "https://api.snapgen.ai/uapi/v1/video-extend/veo";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("prompt", "A serene lake surrounded by mountains at sunset with gentle waves");
formData.append("ref_history", "<uuid video>");

axios.post(url, formData, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```
::

### Request Parameters

`prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The text description of the video you want to generate. Be as descriptive as possible for better results. Include details about movement, scene composition, and visual elements.

`ref_history` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional uuid of the video veo you created by geminigen.

### Response Fields

`id` - Unique identifier for the video generation request

`uuid` - Universal unique identifier for the generated video

`user_id` - User ID who initiated the request

`model_name` - Name of the model used for generation (e.g., veo-2)

`input_text` - The original prompt used for video generation

`type` - Type of media generated (e.g., "video")

`status` - Generation status (1: processing, 2: completed, 3: failed)

`status_desc` - Description of the current status

`status_percentage` - Progress percentage (0-100)

`error_code` - Error code if generation failed

`error_message` - Error message if generation failed

`expired_at` - Expiry time of the video resource

`name` - Name of the video (if any)

`estimated_credit` - Estimated credits used for this request

`media_type` - Media type, e.g., "video"

`created_at` - Date and time the request was created

`updated_at` - Date and time the request was last updated

`delay_seconds` - Delay in seconds before the video starts generating


### Status Codes

- `1` - Processing: The video is being generated
- `2` - Completed: Video generation successful
- `3` - Failed: Generation failed (check error_message)

### Video Extend Mode

Model, Aspect Ratio, and Resolution settings will be automatically set based on your selected video and cannot be modified.

### Tips for Better Results

Create a follow-up video by describing in the prompt what happens starting from the selected image. Be specific about the actions, movements, or changes you want to see in the next section.
