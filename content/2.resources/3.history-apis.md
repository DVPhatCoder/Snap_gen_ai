The snapgen.ai History APIs let you list past generations, inspect a single history item in detail, and delete eligible history records for the current account.

## Before You Start

All endpoints on this page require the `x-api-key` header.

```http
x-api-key: <your api key>
```

Important behavior:

- `GET /histories` returns a wrapper object with `success`, `total`, and `result`
- `GET /history/{conversion_uuid}` returns the history object directly, without a top-level `success` field
- Delete endpoints are soft-delete operations and only delete records that have passed the backend time limit

## Endpoints

| Endpoint | Purpose |
|---|---|
| `GET /uapi/v1/histories` | List paginated history records for the current user |
| `GET /uapi/v1/history/{conversion_uuid}` | Get one history item with nested generated media |
| `DELETE /uapi/v1/histories` | Delete selected eligible history records |
| `DELETE /uapi/v1/histories/all` | Delete all eligible history records |

## Get All Generation History
`GET https://api.snapgen.ai/uapi/v1/histories`

Returns a paginated list of history records for the current user.

### Query Parameters

`filter_by` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Filter by the exact history `type` value. Use `all` to disable type filtering. This value is passed directly to the backend type filter.

`items_per_page` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Number of items to return per page. Default value is `10`.

`page` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Page number for pagination. Default value is `1`.

### Example Request
::code-group
```bash [terminal]
curl -X GET "https://api.snapgen.ai/uapi/v1/histories?filter_by=video&items_per_page=10&page=1" \
  -H "x-api-key: <your api key>"
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/histories"
headers = {
    "x-api-key": "<your api key>"
}
params = {
    "filter_by": "video",
    "items_per_page": 10,
    "page": 1
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript [js]
import axios from 'axios';

const url = "https://api.snapgen.ai/uapi/v1/histories";
const headers = {
    "x-api-key": "<your api key>"
};
const params = {
    filter_by: "video",
    items_per_page: 10,
    page: 1
};

axios.get(url, { headers, params })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```

## Get Specific Generation History
`GET https://api.snapgen.ai/uapi/v1/history/{conversion_uuid}`

Returns a single history record with nested generated media items.

### Path Parameters

`conversion_uuid` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

History UUID.

### Example Request
::code-group
```bash [terminal]
curl -X GET "https://api.snapgen.ai/uapi/v1/history/e5e1b4d4-ec6f-4866-a95b-8e8711fe2f3d" \
  -H "x-api-key: <your api key>"
```

```python [py]
import requests

conversion_uuid = "e5e1b4d4-ec6f-4866-a95b-8e8711fe2f3d"
url = f"https://api.snapgen.ai/uapi/v1/history/{conversion_uuid}"
headers = {
    "x-api-key": "<your api key>"
}

response = requests.get(url, headers=headers)
print(response.json())
```

```javascript [js]
import axios from 'axios';

const conversionUuid = "e5e1b4d4-ec6f-4866-a95b-8e8711fe2f3d";
const url = `https://api.snapgen.ai/uapi/v1/history/${conversionUuid}`;
const headers = {
    "x-api-key": "<your api key>"
};

axios.get(url, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```

## Delete Selected Histories
`DELETE https://api.snapgen.ai/uapi/v1/histories`

Deletes matching history records for the current user.

### Query Parameters

`ids` [integer[]]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional list of numeric history IDs. Repeat the query key for multiple IDs, for example: `?ids=101&ids=102`.

`status` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional status filter. Supported values:

- `processing`
- `successful`
- `failed`
- `queued`

`media_type` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional media type filter. This value is compared directly with the backend history `media_type`.

### Example Request
::code-group
```bash [terminal]
curl -X DELETE "https://api.snapgen.ai/uapi/v1/histories?ids=101&ids=102&status=successful&media_type=video" \
  -H "x-api-key: <your api key>"
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/histories"
headers = {
    "x-api-key": "<your api key>"
}
params = {
    "ids": [101, 102],
    "status": "successful",
    "media_type": "video"
}

response = requests.delete(url, headers=headers, params=params)
print(response.json())
```

```javascript [js]
import axios from 'axios';

const url = "https://api.snapgen.ai/uapi/v1/histories";
const headers = {
    "x-api-key": "<your api key>"
};
const params = {
    ids: [101, 102],
    status: "successful",
    media_type: "video"
};

axios.delete(url, { headers, params })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```
::

### Example Response
```json [Response]
{
  "success": true,
  "result": "2 records deleted"
}
```

### Response Shape
```json [Response]
{
  "success": "boolean",
  "result": "string"
}
```

### Notes

This endpoint only marks records as deleted after each matching record has passed its configured backend time limit. A request can still return `0 records deleted` even when records match the filter.

## Delete All Generation History
`DELETE https://api.snapgen.ai/uapi/v1/histories/all`

Deletes all eligible history records for the current user.

### Example Request
::code-group
```bash [terminal]
curl -X DELETE "https://api.snapgen.ai/uapi/v1/histories/all" \
  -H "x-api-key: <your api key>"
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/histories/all"
headers = {
    "x-api-key": "<your api key>"
}

response = requests.delete(url, headers=headers)
print(response.json())
```

```javascript [js]
import axios from 'axios';

const url = "https://api.snapgen.ai/uapi/v1/histories/all";
const headers = {
    "x-api-key": "<your api key>"
};

axios.delete(url, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```
::

### Example Response
```json [Response]
{
  "success": true,
  "result": "5 records deleted"
}
```

### Notes

Like the filtered delete endpoint, this only marks records as deleted after each record passes its configured backend time limit.
