The snapgen.ai Image Generation API allows you to create stunning, high-quality images from text prompts using state-of-the-art AI models. You can use this API to generate artwork, marketing materials, product mockups, or any visual content you can imagine.

## Generate Image
`POST https://api.snapgen.ai/uapi/v1/generate_image`

This endpoint allows you to generate images from text prompts. You can customize the model, aspect ratio, style, and various other parameters to create the perfect image for your needs.

### Example Request
::code-group
```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/generate_image \
  -H "Content-Type: multipart/form-data" \
  -H "x-api-key: <your api key>" \
  --form "prompt=A beautiful sunset over mountains with vibrant colors" \
  --form "model=nano-banana-pro" \
  --form "aspect_ratio=16:9" \
  --form "style=Photorealistic" \
  --form "file_urls=<url to your file>" \
  --form "resolution=1K"'
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/generate_image"
headers = {
    "x-api-key": "<your api key>"
}
data = {
    "prompt": "A beautiful sunset over mountains with vibrant colors",
    "model": "nano-banana-pro",
    "aspect_ratio": "16:9",
    "style": "Photorealistic",
    "file_urls": "<url to your file>",
    "resolution": "1K"
}

response = requests.post(url, headers=headers, data=data)
print(response.json())
```

```javascript [js]
import axios from 'axios';

const url = "https://api.snapgen.ai/uapi/v1/generate_image";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("prompt", "A beautiful sunset over mountains with vibrant colors");
formData.append("model", "nano-banana-pro");
formData.append("aspect_ratio", "16:9");
formData.append("style", "Photorealistic");
formData.append("file_urls", "<url to your file>");
formData.append("resolution", "1K");

axios.post(url, formData, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```

### Request Parameters

`prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The text description of the image you want to generate. Be as descriptive as possible for better results.

`model` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The AI model to use for image generation. Available models include:
- `nano-banana-pro`
- `nano-banana-2`
- `nano-banana-2-lite`

`aspect_ratio` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The aspect ratio of the generated image. Common options:
- `1:1` - Square (default)
- `16:9` - Widescreen
- `9:16` - Portrait
- `4:3` - Standard
- `3:4` - Portrait standard

The output format of the generated image.
- `jpeg` (default) - JPEG image
- `png` - PNG image

`resolution` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}
- `1K` (default)
- `2K`
- `4K`

`style` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The artistic style to apply to the image:
- `None` - No specific style applied
- `3D Render` - Three-dimensional rendered style
- `Acrylic` - Acrylic painting style
- `Anime General` - General anime/manga style
- `Creative` - Creative and artistic interpretation
- `Dynamic` - Dynamic and energetic style
- `Fashion` - Fashion photography style
- `Game Concept` - Video game concept art style
- `Graphic Design 3D` - 3D graphic design style
- `Illustration` - Digital illustration style
- `Photorealistic` - Realistic photography style
- `Portrait` - Portrait photography style
- `Portrait Cinematic` - Cinematic portrait style
- `Portrait Fashion` - Fashion portrait style
- `Ray Traced` - Ray-traced rendering style
- `Stock Photo` - Stock photography style
- `Watercolor` - Watercolor painting style

`ref_history` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional uuid of the image you created by geminigen.

`files` [array<string>]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional reference images(image local) to guide the generation process. Upload files to use as style, content, or motion references.

`file_urls` [array<string>]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional url images to guide the generation process. Upload files to use as style, content, or motion references.

### Response Fields

`id` - Unique identifier for the generation request

`uuid` - Universal unique identifier for the generated image

`generate_result` - URL to the generated image

`status` - Generation status (1: processing, 2: completed, 3: failed)

`status_percentage` - Progress percentage (0-100)

`used_credit` - Credits consumed for this generation

`file_size` - Size of the generated image in bytes

`thumbnail_small` - URL to a small thumbnail version

### Status Codes

- `1` - Processing: The image is being generated
- `2` - Completed: Image generation successful
- `3` - Failed: Generation failed (check error_message)

### Rate limit

- `nano-banana-pro`: free and 5rq/min, 100rq/hour, 1000rq/day
- `Other models`: not rate limit

### Best Practices

1. **Detailed Prompts**: Use descriptive, specific prompts for better results
2. **Style Consistency**: Choose appropriate styles for your use case
3. **Aspect Ratios**: Select ratios that match your intended use
4. **Safety Filters**: Use appropriate safety levels for your content
5. **Credit Management**: Monitor credit usage for cost optimization
