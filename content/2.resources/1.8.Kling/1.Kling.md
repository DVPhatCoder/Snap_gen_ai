The Kling Video Generation API allows you to create professional-grade videos using state-of-the-art AI models. You can generate videos from text descriptions, apply motion control from reference videos, or edit existing videos with new prompts.

## Generate Video
`POST https://api.snapgen.ai/uapi/v1/video-gen/kling`

This endpoint allows you to generate videos using multiple Kling models. Depending on the model selected, you can provide text prompts, reference videos, reference images, or a combination.


### Example Request

::code-group
```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/video-gen/kling \
  -H "x-api-key: <your api key>" \
  -F "prompt=A woman in red dress walking through a bustling city street at night, neon lights reflecting" \
  -F "model=kling-video-3-0" \
  -F "mode=professional" \
  -F "aspect_ratio=16:9" \
  -F "duration=8" \
  -F "mode_image=default" \
  -F "ref_images=@/path/to/image1.jpg" \
  -F "ref_images=@/path/to/image2.png" \
  -F "ref_videos=@/path/to/reference_video.mp4"
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/video-gen/kling"
headers = {
    "x-api-key": "<your api key>"
}

data = {
    "prompt": "A woman in red dress walking through a bustling city street at night, neon lights reflecting",
    "model": "kling-video-3-0",
    "mode": "professional",
    "aspect_ratio": "16:9",
    "duration": "8",
    "mode_image": "default"
}

files = [
    ("ref_images", ("image1.jpg", open("image1.jpg", "rb"))),
    ("ref_images", ("image2.png", open("image2.png", "rb"))),
    ("ref_videos", ("reference_video.mp4", open("reference_video.mp4", "rb")))
]

response = requests.post(url, headers=headers, data=data, files=files)
print(response.json())
```

```javascript [js]
import axios from 'axios';
import FormData from 'form-data';
import fs from 'fs';

const url = "https://api.snapgen.ai/uapi/v1/video-gen/kling";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("prompt", "A woman in red dress walking through a bustling city street at night, neon lights reflecting");
formData.append("model", "kling-video-3-0");
formData.append("mode", "professional");
formData.append("aspect_ratio", "16:9");
formData.append("duration", "8");
formData.append("mode_image", "default");
formData.append("ref_images", fs.createReadStream("image1.jpg"));
formData.append("ref_images", fs.createReadStream("image2.png"));
formData.append("ref_videos", fs.createReadStream("reference_video.mp4"));

axios.post(url, formData, { headers: { ...headers, ...formData.getHeaders() } })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```

### Request Parameters

`prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The text description of the video you want to generate. Be as descriptive as possible for better results. Minimum 10 characters.

`model` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The Kling AI model to use for video generation. Available models include:

**Text-to-Video / Image-to-Video**
- `kling-video-3-0` - Latest generation, best quality for text-to-video. Supports up to 15 seconds.
- `kling-video-2-6` - Stable model with audio support (`professional_audio` mode for voiceover)
- `kling-video-2-5` - Supports `relax` mode for fastest and cheapest generation
- `kling-video-2-1-5s` - Fixed 5-second output duration
- `kling-video-2-1-10s` - Fixed 10-second output duration

**O1 Variants**
- `kling-video-o1` - O1 variant, optimized for speed and cleaner outputs

**Motion Control**
- `kling-video-motion-3` - Latest motion control model, requires reference video + image
- `kling-video-motion` - Motion control, requires reference video + image

**Edit**
- `kling-video-3-0-edit` - Edit existing videos using kling-3.0, requires original video + key frame
- `kling-video-o1-edit` - Edit existing videos using o1 variant, requires original video + key frame

**Lipsync**
- `kling-video-lipsync` - Sync lip movement to provided audio/speech

`mode` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The generation mode affecting quality and speed:

- `standard` - 720p output, good quality, balanced processing (default). Available for all models.
- `professional` - 1080p output, higher quality, slower processing. Available for all models.
- `professional_audio` - 1080p output with voiceover/audio generation. Only for `kling-video-2-6`.
- `relax` - 720p output, lowest cost, fastest processing. Only for `kling-video-2-5`.

`aspect_ratio` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The aspect ratio of the generated video:

- `16:9` - Widescreen/landscape (default)
- `9:16` - Portrait for mobile/shorts
- `1:1` - Square for social media

`duration` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Duration of the generated video in seconds.

- Default: `5`
- Range: `3` to `15` seconds (depends on model)

`ref_videos` [array<file>]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Reference video files. **Required for motion control and edit models**.

- Formats: MP4, MOV, WebM
- Max size: 100MB per file
- Max duration: 120 seconds

`ref_images` [array<file>]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Reference image files. **Required for motion control and edit models**. Optional for text-to-video (improves consistency).

- Formats: JPG, PNG
- Max size: 10MB per file

### Response Fields

`id` - Unique integer identifier for the generation request

`uuid` - Universal unique identifier for tracking the generation

`user_id` - ID of the user who submitted the request

`model_name` - The model used for generation (e.g. `kling-video-3-0`)

`input_text` - The prompt text submitted by the user

`type` - Generation type (e.g. `video`)

`status` - Generation status as an integer code (`0` = pending, `1` = processing, `2` = completed, `3` = error)

`status_desc` - Human-readable description of the current status

`status_percentage` - Progress percentage (0–100)

`error_code` - Error code if the generation failed, otherwise empty

`error_message` - Error detail message if the generation failed, otherwise empty

`estimated_credit` - Credits consumed for this generation

`media_type` - Type of the output media (e.g. `video`)

`media_files` - Array of generated video file objects (populated when generation is complete)

`created_at` - Timestamp when the request was created (ISO 8601)

`updated_at` - Timestamp when the request was last updated, or `null` if not yet updated

`delay_seconds` - Queue delay in seconds before processing began

### Status Codes

- `pending` - Request queued, waiting for processing
- `converting` - Video is being generated
- `completed` - Generation successful
- `error` - Generation failed (check error_message)


### Best Practices

1. **Detailed Prompts**: Use descriptive, specific prompts (50-200 characters ideal)
2. **Choose the Right Model**: Text-to-video for simple generation, motion for precise control, edit for modifications
3. **Optimize Duration**: Start with 5 seconds to test before committing to longer durations
4. **Use Reference Images**: Even for text-to-video, reference images improve consistency
5. **Credit Management**: Monitor credit usage; standard mode costs less than professional

### Common Use Cases

- **Social Media Content**: Short-form videos for TikTok, Reels, Shorts
- **Marketing Materials**: Product demos, advertisements, brand stories
- **Creative Projects**: Music videos, artistic animations, concept visuals
- **Corporate Communications**: Presentations with voiceover, training videos
- **Character Animation**: Motion-controlled character movements from reference videos
- **Video Enhancement**: Background replacement, style transfer, scene modification
