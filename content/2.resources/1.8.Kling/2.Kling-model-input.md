## Unified Endpoint
`POST https://api.snapgen.ai/uapi/v1/video-gen/kling`

All Kling models share the same endpoint. Validation logic depends entirely on the `model` parameter you send.

---

## Required vs Optional Parameters

### Always Required

`prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

Text description of the video. Minimum length validation applies at backend level.

`model` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

One of the 13 Kling model identifiers. See [Model List](#model-list) below.

### Optional Parameters (with defaults)

| Parameter | Default | Description |
|-----------|---------|-------------|
| `mode` | `standard` | Generation quality/speed mode |
| `aspect_ratio` | `16:9` | Video aspect ratio |
| `duration` | `5` | Duration in seconds (may be overridden by ref_video) |
| `ref_images` | `None` | Reference image files or URLs |
| `ref_videos` | `None` | Reference video files or URLs |
| `mode_image` | `DEFAULT` | Image processing mode |

Text-to-Video (Prompt Only):
  - kling-video-3-0        # Latest, best quality

```yaml

```

```yaml
Edit Models (Video Required):

```

## Video-Required Models (Backend Validation)



```python
"kling-video-motion",
"kling-video-motion-3", 
"kling-video-3-0-edit",
"kling-video-o1-edit"

```

### Validation Rule

If `model` is in this set:
- **Must have** at least 1 `ref_video`
- `duration` is **overridden** by the duration of the first reference video
- `duration` parameter in request is ignored

### Error Response When Missing

```json
{
  "detail": {
    "error_code": "INVALID_VIDEO_FILE",
    "error_message": "Model 'kling-video-motion-3' requires at least one reference video."
  }
}
```

### Example: Correct Request for Motion Model

```bash
curl -X POST https://api.imagen.ai/user-api/v1/video/video-gen/kling \
  -H "x-api-key: <your-api-key>" \
  -F "prompt=A dancer moving gracefully on stage" \
  -F "model=kling-video-motion-3" \
  -F "ref_videos=@motion_reference.mp4" \
  -F "ref_images=@pose.jpg"
```

## File Upload Constraints

From `app/api/user_api/v1/video/kling.py`:

### Images (`ref_images`)

| Constraint | Value | Source |
|------------|-------|--------|
| Max size | `settings.MAX_REF_IMAGE_SIZE_BYTES` | Backend config |
| Formats | JPG, PNG | Validation |
| Max files | 4 | Implementation limit |

### Videos (`ref_videos`)

| Constraint | Value | Source |
|------------|-------|--------|
| Max size | `settings.MAX_REF_VIDEO_SIZE_BYTES` | Backend config |
| Max duration | `settings.MAX_REF_VIDEO_DURATION_SECONDS` | Backend config |
| Formats | MP4, MOV, WebM | Validation |
| Max files | 1 | Implementation limit |

### File Error Responses

#### FILE_TOO_LARGE

```json
{
  "detail": {
    "error_code": "FILE_TOO_LARGE",
    "error_message": "Image file size exceeds limit."
  }
}
```

#### VIDEO_DURATION_TOO_LONG

```json
{
  "detail": {
    "error_code": "VIDEO_DURATION_TOO_LONG",
    "error_message": "Reference video duration exceeds maximum allowed."
  }
}
```

#### INVALID_VIDEO_FILE

```json
{
  "detail": {
    "error_code": "INVALID_VIDEO_FILE",
    "error_message": "Unsupported video format or corrupted file."
  }
}
```

## Duration Behavior by Model Type

### Text-to-Video Models
- User-provided `duration` is respected
- Range: 3-15 seconds (model dependent)
- Default: 5 seconds

### Motion Control & Edit Models
- `duration` is **automatically extracted** from first `ref_video`
- User-provided `duration` is **ignored**
- No validation needed - uses source video duration

## Error Code Quick Reference

| Error Code | When It Occurs | Solution |
|------------|----------------|----------|
| `INVALID_VIDEO_FILE` | Motion/edit model without ref_videos | Add ref_videos |
| `FILE_TOO_LARGE` | Image > 10MB or Video > 100MB | Compress file |
| `VIDEO_DURATION_TOO_LONG` | ref_video > max duration | Trim video |
| `SERVICE_PRICE_NOT_FOUND` | Invalid model-mode combination | Check mode validity table |
| `EMPTY_PROMPT` | prompt missing or too short | Add detailed prompt |
| `INVALID_INPUT` | Parameter value out of range | Validate parameters |

## Integration Checklist

Before calling the API for a specific model:

### For ALL models:
- `prompt` is provided 
- `model` is one of the 13 valid values

### For Motion/Edit models:
- At least 1 `ref_video` is provided
- `ref_video` duration ≤ max allowed
- `ref_video` size ≤ max allowed
- `ref_images` recommended for better results

### For kling-video-2-6 with audio:
- `mode` = `professional_audio` (not standard/professional)

### For kling-video-2-5:
- `mode` can be `relax` (budget), `standard`, or `professional`

### File validation:
- Images: JPG/PNG, < max size
- Videos: MP4/MOV/WebM, < max size, < max duration
