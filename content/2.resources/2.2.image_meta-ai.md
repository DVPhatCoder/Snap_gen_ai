The Meta AI Image Generation API allows you to create high-quality images from text prompts using Meta AI models. It supports reference images from previous generations or uploaded files to guide the output.

## Generate Image (Meta AI)
`POST https://api.snapgen.ai/uapi/v1/meta_ai/generate`

This endpoint generates images using Meta AI. It supports prompt-based generation, optional reference images, and multiple outputs.

---

## Example Request
::code-group

```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/meta_ai/generate \
  -H "x-api-key: <your api key>" \
  -H "Content-Type: multipart/form-data" \
  --form "prompt=A cyberpunk robot in a futuristic city" \
  --form "orientation=landscape" \
  --form "num_result=2" \
  --form "ref_history=<history_uuid>" \
  --form "files=@ref1.png" \
  --form "files=@ref2.jpg"
````

```python [py] id="meta-ai-py"
import requests

url = "https://api.snapgen.ai/uapi/v1/meta_ai/generate"
headers = {
    "x-api-key": "<your api key>"
}

files = [
    ("files", open("ref1.png", "rb")),
    ("files", open("ref2.jpg", "rb"))
]

data = {
    "prompt": "A cyberpunk robot in a futuristic city",
    "orientation": "landscape",
    "num_result": 2,
    "ref_history": "<history_uuid>"
}

response = requests.post(url, headers=headers, data=data, files=files)
print(response.json())
```

## Request Parameters

`prompt` [string] *required*
The text prompt describing the image you want to generate.

---

`orientation` [string]
Image orientation:

* `landscape` (default)
* `portrait`
* `square`

---

`num_result` [integer]
Number of images to generate:

* `1` (default)
* `2`
* `3`
* `4`

---

`ref_history` [string]
UUID of a previously generated image.
Used as a reference for new image generation.

---

`files` [array<File>]
Optional uploaded reference images.

Supported formats:

* `.png`
* `.jpg`
* `.jpeg`
* `.webp`

---

## How Reference Images Work

You can provide reference images in two ways:

### 1. From History (`ref_history`)

* Uses previously generated images
* Must belong to the current user
* Must be of type `image`

---

### 2. Upload Files (`files`)

* Local files sent via multipart form
* Used as style/content reference

## Response Fields

`id`
Unique identifier of the request



`uuid`
Unique identifier for tracking generation

`user_id`
ID of the user making the request

`model_name`
AI model used (`meta-ai-image`)

`input_text`
Original prompt

`generate_result`
URL to generated images (available after processing)

`status`
Current processing status

`status_desc`
Human-readable status

`created_at`
Timestamp of request creation

## Status Codes

* `1` - Processing
* `2` - Completed
* `3` - Failed

---

## Workflow

1. Send request → receive `uuid`
2. System processes in background
3. Use history API to retrieve result

---

## Notes

* Image generation runs asynchronously
* Uploaded files are stored temporarily and cleaned up automatically
* Reference images improve generation quality
* `num_result` impacts processing time

---
## Best Practices

1. **Write detailed prompts**
   → Improves image quality

2. **Use reference images**
   → Better consistency

3. **Keep `num_result` low**
   → Faster processing

4. **Reuse previous generations**
   → Iterative improvements
