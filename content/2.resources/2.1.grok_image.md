The Grok Image Generation API allows you to create high-quality images from text prompts using the Grok AI model. It supports reference images from previous generations or uploaded files to guide the output.
## Generate Image (Grok)
`POST https://api.snapgen.ai/uapi/v1/imagen/grok`

This endpoint generates images using the Grok model. It supports prompt-based generation, optional reference images, and multiple output images.

## Example Request
::code-group

```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/imagen/grok \
  -H "x-api-key: <your api key>" \
  -H "Content-Type: multipart/form-data" \
  --form "prompt=A futuristic city with neon lights at night" \
  --form "orientation=landscape" \
  --form "num_result=2" \
  --form "mode=SPEED" \
  --form "ref_history=<history_uuid>" \
  --form "files=@image1.png" \
  --form "files=@image2.jpg"
````

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/imagen/grok"
headers = {
    "x-api-key": "<your api key>"
}

files = [
    ("files", open("image1.png", "rb")),
    ("files", open("image2.jpg", "rb"))
]

data = {
    "prompt": "A futuristic city with neon lights at night",
    "orientation": "landscape",
    "num_result": 2,
    "mode": "SPEED",
    "ref_history": "<history_uuid>"
}

response = requests.post(url, headers=headers, data=data, files=files)
print(response.json())
```

## Request Parameters

`prompt` [string] *required*
The text prompt describing the image you want to generate.

---
`orientation` [string]
Image orientation:
* `landscape` (default)
* `portrait`
* `square`

---

`num_result` [integer]
Number of images to generate (1 → 8). Default is `1`.

---

`mode` [string]
Generation mode:
* `SPEED` (default)
* `QUALITY`

Use `SPEED` for faster generation, or `QUALITY` when output quality is the priority.
When using `QUALITY`, you can generate up to 4 images per request.

---

`ref_history` [string]
UUID of a previously generated image.
The system will use that image as a reference.

---

`files` [array<File>]
Optional uploaded images used as references.
Supported formats:

* `.png`
* `.jpg`
* `.jpeg`
* `.webp`

---

## How Reference Images Work

You can provide reference images in two ways:

1. **From history (`ref_history`)**

   * Uses previously generated images
   * Must belong to the current user

2. **Upload files (`files`)**

   * Local images sent via multipart form
   * Used as style/content guidance

---

## Response Fields

`id`
Unique identifier of the request

`uuid`
Unique identifier for tracking generation

`user_id`
ID of the user making the request

`model_name`
AI model used (`grok-image`)

`input_text`
Original prompt

`generate_result`
URL to generated images (available after completion)

`status`
Current processing status

`status_desc`
Human-readable status

`created_at`
Timestamp of request creation

---

## Status Codes

* `1` - Processing
* `2` - Completed
* `3` - Failed

---

## Workflow

1. Send request → receive `uuid`
2. System processes in background
3. Use history API to check result

---

## Notes

* Image generation runs asynchronously
* Temporary uploaded files are automatically cleaned up
* Reference images improve quality and consistency
* `num_result` affects processing time

---

## Best Practices

1. **Use clear prompts**
   → More detail = better image

2. **Use reference images**
   → Helps control style and consistency

3. **Limit number of results**
   → Faster response

4. **Reuse history**
   → Build iterative generations
