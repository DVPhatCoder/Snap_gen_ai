The snapgen.ai Storyboard API lets you generate a multi-scene video by chaining Grok video clips together. Each scene is rendered independently — the last frame of scene N is automatically used as the reference image for scene N+1 (chain-extend pattern). All clips are merged into one final video.

## Generate Storyboard (Grok)
`POST https://api.snapgen.ai/uapi/v1/video-storyboard/grok`

### Example Request
::code-group
```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/video-storyboard/grok \
  -H "Content-Type: multipart/form-data" \
  -H "x-api-key: <your api key>" \
  --form 'scenes=[{"prompt":"A sunrise over a mountain range","duration":6,"mode":"custom"},{"prompt":"A river flowing through the valley below","duration":6,"mode":"custom"},{"prompt":"A village waking up at dawn","duration":10,"mode":"custom"}]' \
  --form "aspect_ratio=landscape" \
  --form "resolution=720p" \
  --form "model=grok-video"
```

```python [py]
import requests
import json

url = "https://api.snapgen.ai/uapi/v1/video-storyboard/grok"
headers = {
    "x-api-key": "<your api key>"
}
data = {
    "scenes": json.dumps([
        {"prompt": "A sunrise over a mountain range", "duration": 6, "mode": "custom"},
        {"prompt": "A river flowing through the valley below", "duration": 6, "mode": "custom"},
        {"prompt": "A village waking up at dawn", "duration": 10, "mode": "custom"},
    ]),
    "aspect_ratio": "landscape",
    "resolution": "720p",
    "model": "grok-video",
}

response = requests.post(url, headers=headers, data=data)
print(response.json())
```

```javascript [js]
import axios from 'axios';
import FormData from 'form-data';

const url = "https://api.snapgen.ai/uapi/v1/video-storyboard/grok";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("scenes", JSON.stringify([
    { prompt: "A sunrise over a mountain range", duration: 6, mode: "custom" },
    { prompt: "A river flowing through the valley below", duration: 6, mode: "custom" },
    { prompt: "A village waking up at dawn", duration: 10, mode: "custom" },
]));
formData.append("aspect_ratio", "landscape");
formData.append("resolution", "720p");
formData.append("model", "grok-video");

axios.post(url, formData, { headers: { ...headers, ...formData.getHeaders() } })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```

### Request Parameters

`scenes` [JSON string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

A JSON-encoded array of scene objects. Each scene defines the prompt, duration, and mode for one clip.

**Scene object fields:**

`scenes[].prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

Text description of the scene.

`scenes[].duration` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

Duration of the scene in seconds. Allowed values: `6`, `10`.

`scenes[].mode` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Generation mode. Always normalized to `custom` by the API regardless of the value provided.

---

`aspect_ratio` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Aspect ratio applied to all scenes. Available options:
- `landscape` (16:9) — Default
- `portrait` (9:16)
- `square` (1:1)

`resolution` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Resolution of the generated video. Available options:
- `480p` — Default
- `720p`

> **Note:** `1080p` is automatically downgraded to `720p`.

`model` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The model to use. Available options:
- `grok-video` — Default
- `grok-3` — Alias for `grok-video`

---

### Constraints

| Rule | Value |
|---|---|
| Minimum scenes | 2 |
| Maximum scenes | 10 |
| Maximum total duration | 45 seconds |
| Allowed durations per scene | `6s` or `10s` |
| Allowed aspect ratios | `landscape`, `portrait`, `square` |

### Response Fields

`id` - Unique identifier for the storyboard generation request

`uuid` - Universal unique identifier for the generated storyboard video

`user_id` - User ID who initiated the request

`model_name` - Name of the model used for generation (e.g., `grok-video`)

`input_text` - The prompt from the first scene

`type` - Type of media generated (`video`)

`status` - Generation status (`1`: processing, `2`: completed, `3`: failed)

`status_desc` - Description of the current status

`status_percentage` - Progress percentage (0–100). Scene processing updates this incrementally up to 90%; the final merge and upload bring it to 100%.

`error_code` - Error code if generation failed

`error_message` - Error message if generation failed

`expired_at` - Expiry time of the video resource

`name` - Name of the video (if any)

`estimated_credit` - Estimated credits used for this request (sum across all scenes)

`media_type` - Media type (`video`)

`created_at` - Date and time the request was created

`updated_at` - Date and time the request was last updated

`delay_seconds` - Delay in seconds before generation starts

| `PREMIUM_PLAN_REQUIRED` | 403 | Premium plan required. Upgrade at https://snapgen.ai/pricing |
| `EMPTY_PROMPT` | 400 | Prompt for scene N cannot be empty. |
| `TOO_FEW_SCENES` | 400 | A storyboard requires at least 2 scenes. |
| `TOO_MANY_SCENES` | 400 | A storyboard supports at most 10 scenes. |
| `TOTAL_DURATION_EXCEEDED` | 400 | Total duration exceeds the maximum 45s allowed. |
| `INVALID_DURATION` | 400 | Scene N: duration must be 6 or 10 seconds. |
| `INVALID_ASPECT_RATIO` | 400 | Aspect ratio must be one of: `landscape`, `portrait`, `square`. |
| `NOT_ENOUGH_CREDIT` | 402 | Insufficient credits to complete the request. |
| `NOT_ENOUGH_AND_LOCK_CREDIT` | 402 | Not enough credit due to locked credit. Check your transaction history. |
| `SERVICE_PRICE_NOT_FOUND` | 500 | Storyboard service pricing is not configured. Please contact support. |
| `SERVICE_UNAVAILABLE` | 503 | Server is experiencing high traffic. Please try again in 30 minutes. |
