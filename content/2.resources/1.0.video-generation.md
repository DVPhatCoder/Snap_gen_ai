The snapgen.ai Video Generation API allows you to create high-quality videos from text prompts using state-of-the-art AI models. You can use this API to generate video content, animations, marketing materials, or any visual video content you can imagine.

## Generate Video Veo
`POST https://api.snapgen.ai/uapi/v1/video-gen/veo`

This endpoint allows you to generate videos from text prompts using the Veo model. You can customize the resolution, duration, aspect ratio, and various other parameters to create the perfect video for your needs.

### Example Request
::code-group
```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/video-gen/veo \
  -H "Content-Type: multipart/form-data" \
  -H "x-api-key: <your api key>" \
  --form "prompt=A serene lake surrounded by mountains at sunset with gentle waves" \
  --form "model=veo-2" \
  --form "resolution=720p" \
  --form "duration=8" \
  --form 'aspect_ratio="16:9"' \
  --form 'ref_images=@"<local to your file>"' \
  --form 'ref_images="<url to your file>"' \
  --form 'mode_image="frame"'
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/video-gen/veo"
headers = {
    "x-api-key": "<your api key>"
}
data = {
    "prompt": "A serene lake surrounded by mountains at sunset with gentle waves",
    "model": "veo-2",
    "resolution": "720p",
    "duration": 8,
    "aspect_ratio": "16:9",
    "mode_image": "frame",
    "ref_images": "<url to your file>"  # Replace with your file URL or remove if not using
}

files = {
    "ref_images": open("<path to local image>", "rb")   # remove this option if you are not using a local image
}

response = requests.post(url, headers=headers, data=data, files=files)
print(response.json())
```

```javascript [js]
import axios from 'axios';
import FormData from "form-data";
import fs from "fs";

const url = "https://api.snapgen.ai/uapi/v1/video-gen/veo";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("prompt", "A serene lake surrounded by mountains at sunset with gentle waves");
formData.append("model", "veo-2");
formData.append("resolution", "720p");
formData.append("duration", "8");
formData.append("aspect_ratio", "16:9");
formData.append("ref_images", "<url to your file>");
formData.append("ref_images", fs.createReadStream("./image.png"));
formData.append("mode_image", "frame");

axios.post(url, formData, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```

### Request Parameters

`prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The text description of the video you want to generate. Be as descriptive as possible for better results. Include details about movement, scene composition, and visual elements.

`model` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The AI model to use for video generation. Available models include:
- `veo-3.1` - Latest high-quality video generation model with enhanced capabilities
- `veo-3.1-fast` - Faster version of Veo 3.1 with optimized processing speed
- `veo-2` - Advanced video generation model with flexible duration options
- `veo-3.1-lite` - Veo 3.1 Lite creates video with synchronized audio.
- `omni-flash` - Omni Flash(gen video 10s or edit video)

<!-- `enhance_prompt` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

Whether to enhance the prompt automatically for better video generation results. Set to `true` to improve prompt quality or `false` to use the original prompt as-is. -->

`resolution` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The resolution of the generated video. Available options:
- `720p` - High definition (1280x720)
- `1080p` - Full high definition (1920x1080)

Note:
- Veo2: only 720p resolution

`duration` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The duration of the generated video in seconds:
- `4` - Video 4s
- `6` - Video 6s
- `8` - Video 8s
- `10` - Video 10s(Only Omni-Flash)

<!-- `negative_prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Text describing what you don't want to see in the video. This helps guide the model away from unwanted elements or styles. -->

`aspect_ratio` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The aspect ratio of the generated video. Common options:
- `16:9` - Widescreen (default for most content)
- `9:16` - Portrait (ideal for mobile/social media)

`mode_image` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

The mode image of the generated video. Common options:
- `frame` - Frame Images(default) - 1 or 2 images
- `ingredient` - Ingredient Images - 1 or 2 or 3 images

`ref_images` [array<string>]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional reference images(image local) or url images to guide the generation process. Upload files to use as style, content, or motion references.
The maximum limit is 2 images with frame, 3 images with ingredient.

Note:

We will soon be removing `files`, `file_urls`, or `ref_history` and only using `ref_images`. Please switch your code as soon as possible.

If you use `files`, `file_urls`, or `ref_history`, we will only use one image to create the video, even if you upload multiple images.

`ref_images` only supports one or two images with frame mode image. Please submit them in the correct order to correspond to the start and end frames. Submitting more than one image may cause errors.

`ref_videos` [array<string>]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Optional reference videos(video local) or url videos to guide the generation process. Upload files to use as style, content, or motion references.
Only use Omni-Flash.
## Model Specifications

### Veo 3.1
The latest and most advanced video generation model with enhanced quality and capabilities.

**Features:**
- **Aspect Ratios**: 16:9 (widescreen)
- **Duration**: 8 seconds (fixed)
- **Resolutions**: 720p, 1080p (default: 720p)
- **Enhance Prompt**: Always enabled and locked
- **Supported Options**: Style customization, video dimensions, image input, resolution control

**Best For:** High-quality professional video content, marketing materials, and premium visual content.

### Veo 3.1 Fast
Optimized version of Veo 3.1 designed for faster processing while maintaining high quality.

**Features:**
- **Aspect Ratios**: 16:9 (widescreen)
- **Duration**: 8 seconds (fixed)
- **Resolutions**: 720p, 1080p (default: 720p)
- **Enhance Prompt**: Always enabled and locked
- **Supported Options**: Style customization, video dimensions, image input, resolution control

**Best For:** Quick turnaround projects, rapid prototyping, and when speed is prioritized over maximum quality.

### Veo 2
Advanced video generation model with flexible duration options and multiple aspect ratios.

**Features:**
- **Aspect Ratios**: 16:9 (widescreen), 9:16 (portrait)
- **Duration**: 8 seconds (fixed)
- **Resolutions**: Various options available
- **Enhance Prompt**: Enabled by default but can be disabled
- **Supported Options**: Style customization, video dimensions, image input, duration control

**Best For:** Social media content, mobile-first videos, and projects requiring specific duration control.

### Response Fields

`id` - Unique identifier for the video generation request

`uuid` - Universal unique identifier for the generated video

`user_id` - User ID who initiated the request

`model_name` - Name of the model used for generation (e.g., veo-2)

`input_text` - The original prompt used for video generation

`type` - Type of media generated (e.g., "video")

`status` - Generation status (1: processing, 2: completed, 3: failed)

`status_desc` - Description of the current status

`status_percentage` - Progress percentage (0-100)

`error_code` - Error code if generation failed

`error_message` - Error message if generation failed

`expired_at` - Expiry time of the video resource

`name` - Name of the video (if any)

`estimated_credit` - Estimated credits used for this request

`media_type` - Media type, e.g., "video"

`created_at` - Date and time the request was created

`updated_at` - Date and time the request was last updated

`delay_seconds` - Delay in seconds before the video starts generating

### Status Codes

- `1` - Processing: The video is being generated
- `2` - Completed: Video generation successful
- `3` - Failed: Generation failed (check error_message)

### Best Practices

1. **Detailed Prompts**: Use descriptive, specific prompts that include movement and scene details
2. **Duration Planning**: Consider the complexity of your scene when choosing duration
3. **Resolution Selection**: Choose appropriate resolution for your intended use case
4. **Aspect Ratio**: Select ratios that match your target platform or use case
5. **Credit Management**: Video generation typically uses more credits than image generation

### Common Use Cases

- **Marketing Videos**: Product demonstrations, promotional content, social media videos
- **Creative Projects**: Short films, animations, artistic expressions
- **Content Creation**: Video thumbnails, background videos, visual storytelling
- **Prototyping**: Concept videos, storyboard visualization, motion studies
- **Education**: Instructional videos, animated explanations, visual demonstrations

### Tips for Better Results

1. **Motion Description**: Include specific details about how objects should move
2. **Scene Composition**: Describe camera angles, lighting, and scene layout
3. **Temporal Elements**: Mention timing and sequence of events in your prompt
4. **Style Consistency**: Use consistent terminology for visual style throughout
5. **Reference Files**: Upload reference images or videos for better style matching
