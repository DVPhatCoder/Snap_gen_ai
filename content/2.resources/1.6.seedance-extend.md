The snapgen.ai Video Generation API allows you to extend high-quality videos using state-of-the-art Seedance AI models. You can use this API to seamlessly lengthen existing Seedance-generated videos.

## Extend Video Seedance
`POST https://api.snapgen.ai/uapi/v1/video-extend/seedance`

This endpoint allows you to extend videos generated by Seedance models.

### Example Request
::code-group
```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/video-extend/seedance \
  -H "Content-Type: multipart/form-data" \
  -H "x-api-key: <your api key>" \
  --form "prompt=The dynamic dance performance continues into a massive stadium" \
  --form "ref_history=<uuid video>"
```

```python [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/video-extend/seedance"
headers = {
    "x-api-key": "<your api key>"
}
data = {
    "prompt": "The dynamic dance performance continues into a massive stadium",
    "ref_history": "<uuid video>"
}

response = requests.post(url, headers=headers, data=data)
print(response.json())
```

```javascript [js]
import axios from 'axios';
import FormData from "form-data";

const url = "https://api.snapgen.ai/uapi/v1/video-extend/seedance";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("prompt", "The dynamic dance performance continues into a massive stadium");
formData.append("ref_history", "<uuid video>");

axios.post(url, formData, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```
::

### Request Parameters

`prompt` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The text description of the extended video. Be specific about the actions, movements, or changes you want to see continuing from the previous video sequence.

`ref_history` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"} *required*

The uuid of the Seedance video you previously created using GeminiGen.

### Response Fields

`id` - Unique identifier for the video generation request

`uuid` - Universal unique identifier for the generated video

`user_id` - User ID who initiated the request

`model_name` - Name of the model used for generation (e.g., seedance-2-omni)

`input_text` - The original prompt used for video generation

`type` - Type of media generated (e.g., "video")

`status` - Generation status (1: processing, 2: completed, 3: failed)

`status_desc` - Description of the current status

`status_percentage` - Progress percentage (0-100)

`error_code` - Error code if generation failed

`error_message` - Error message if generation failed

`expired_at` - Expiry time of the video resource

`name` - Name of the video (if any)

`estimated_credit` - Estimated credits used for this request

`media_type` - Media type, e.g., "video"

`created_at` - Date and time the request was created

`updated_at` - Date and time the request was last updated

`delay_seconds` - Delay in seconds before the video starts generating


### Status Codes

- `1` - Processing: The video is being generated
- `2` - Completed: Video generation successful
- `3` - Failed: Generation failed (check error_message)

### Video Extend Mode

Model, Mode, Duration, Aspect Ratio, and other settings will be automatically set based on your original Seedance video and cannot be modified in an extend request.

### Tips for Better Results

Create a continuous video flow by describing in the prompt what happens specifically *after* the events of the selected video. Ensure characters and scenes logically progress to maintain Seedance's cinematic continuity.
