Use this endpoint to retrieve account details, current credit balance, and active benefits attached to your plan.

## Get Account Info
`GET https://api.snapgen.ai/uapi/v1/account`

### Example Request
::code-group
```bash [terminal]
curl -L 'https://api.snapgen.ai/uapi/v1/account' \
  -H 'Accept: application/json' \
  -H 'x-api-key: <your api key>'
```

```ts [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/account"
headers = {
    "Accept": "application/json",
    "x-api-key": "<your api key>"
}

response = requests.get(url, headers=headers)
print(response.json())
```

```ts [ts]
import axios from 'axios';

const url = "https://api.snapgen.ai/uapi/v1/account";
const headers = {
  Accept: "application/json",
  "x-api-key": "<your api key>"
};

axios.get(url, { headers })
  .then(response => console.log(response.data))
  .catch(error => console.error(error));
```
::

### Response Attributes

`uuid` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Unique identifier for the account.

`is_active` [boolean]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Indicates whether the account is active.

`full_name` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Display name for the account.

`email` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Account email address.

`plan_id` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Current plan identifier.

`user_credit` [object]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Credit summary for the account.

`user_credit.locked_credit` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Credits currently locked by in-progress or pending jobs.

`user_credit.available_credit` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Credits available for new requests.

`user_benefits` [array]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

List of active and inactive benefits on the account.

`user_benefits[].id` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

Benefit record identifier.

`user_benefits[].product` [object]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

`user_benefits[].product.id` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

`user_benefits[].product.name` [string]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}

`user_benefits[].product.type` [integer]{style="color: rgb(var(--color-gray-400) / var(--tw-text-opacity, 1)); font-weight: 300;"}
