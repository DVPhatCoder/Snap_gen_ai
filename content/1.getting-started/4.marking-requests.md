After setting up your account and obtaining your API key, setup webhooks, you can start making requests to the snapgen.ai API. This guide will walk you through the process of making your first request and provide examples of how to use the API to generate images, videos, and more.

::code-group

```bash [terminal]
curl -X POST https://api.snapgen.ai/uapi/v1/video-gen/veo \
  -H "Content-Type: multipart/form-data" \
  -H "x-api-key: <your api key>" \
  --form "prompt=A serene lake surrounded by mountains at sunset with gentle waves" \
  --form "model=veo-2" \
  --form "resolution=720p" \
  --form 'aspect_ratio="16:9"'
```

```ts [py]
import requests

url = "https://api.snapgen.ai/uapi/v1/video-gen/veo"
headers = {
    "x-api-key": "<your api key>"
}
data = {
    "prompt": "A serene lake surrounded by mountains at sunset with gentle waves",
    "model": "veo-2",
    "resolution": "720p",
    "aspect_ratio": "16:9"
}

response = requests.post(url, headers=headers, data=data)
print(response.json())
```

```ts [ts]
import axios from 'axios';
import FormData from 'form-data';

const url = "https://api.snapgen.ai/uapi/v1/video-gen/veo";
const headers = {
    "x-api-key": "<your api key>"
};

const formData = new FormData();
formData.append("prompt", "A serene lake surrounded by mountains at sunset with gentle waves");
formData.append("model", "veo-2");
formData.append("resolution", "720p");
formData.append("aspect_ratio", "16:9");

axios.post(url, formData, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error));
```
